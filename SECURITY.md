# Security

Scribo records which inputs each pipeline result came from, in the same study database as Colligo. Please report a vulnerability privately, never in a public issue.

## Reporting

Use GitHub's private vulnerability reporting: the "Report a vulnerability" button under the Security tab of this repository. Include the version, what you observed, and how to reproduce it with synthetic data.

Never attach real patient, restricted or controlled-access data to a report, not even a file name.

## Scope

In scope: anything that exposes data of a restricted study, and anything that makes Scribo report a result as current when its inputs changed.
